# Security policy

Please report security or accidental-disclosure issues privately to [pete@quadmresearch.com](mailto:pete@quadmresearch.com). Include the affected file, a minimal reproduction, and the impact.

Do not open a public issue containing credentials, private datasets, bookmaker payloads, or details that expose another system. Revoke or rotate a real credential before reporting it.

The latest revision of `main` is supported. This repository is a local research case study, not a hosted service. Reports about source-hash verification, path handling, unsafe downloads, or a way to bypass point-in-time validation are in scope.
